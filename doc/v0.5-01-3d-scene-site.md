## 背景与目标

`campus-ai-workshop/` 已交付一份 65 页企划书（100㎡ 校园「咖啡馆 + AI 共创空间」）。企划书第三章把空间拆成了 12×8 格网上的六个分区、四种时段形态与五感验收参数，但读者只能看静态等距插画（`images/space.png`）与表格，无法感知「同一个空间在不同时段服务完全不同的人」这一核心主张。

本次要做的是一个**可交互的 3D 展示站**：把 100㎡ 空间按格网规格建成实时 WebGL 模型，用鼠标环绕观察、点击分区看配置、切换四个时段看灯光与人群变化、动画演示讲座角变形。视觉层直接使用 `animal-island-ui`（动森风格）组件库，与该库的奶油底 + 棕字 + 青绿主色体系一致，也与企划书自身的暖木/墨绿/奶油色板天然契合。

## 已确认决策

| 项 | 决定 |
|---|---|
| 3D 交互 | 环绕展示台（娃娃屋视角）：旋转/缩放 + 点击分区 + 四时段切换 + 讲座角变形动画。不做第一人称漫游 |
| 站点范围 | 单页：3D 主场景 + 六分区配置表 + 五感氛围参数 + 一天四张脸 + 核心数字条 |
| 技术形态 | Vite + npm 依赖，React + TypeScript + three.js + @react-three/fiber + @react-three/drei |
| UI 组件 | **直接安装 `animal-island-ui` 2.0.0 原包**用其真实组件（不自行重实现） |

## 3D 场景规格

**坐标系**：全部按企划书格网 1:1 建模，房间 12m(X, 西→东) × 8.33m(Z, 北→南) × 3.2m 层高；所有分区包在 `<group position={[-6,0,-4.165]}>` 内，使原点即房间中心（OrbitControls target = 原点）。

**分区（以 03-space.html 的 grid-area 为准，不得改动）**

| 分区 | X | Z | 面积 | 必备物件 |
|---|---|---|---|---|
| 吧台与点单区 | 0–3 | 0–4.17 | 12㎡ | 吧台 + 双头咖啡机、磨豆机、糕点柜、冷藏柜、3 高脚凳、菜单看板、黑板 |
| 共创长桌区 | 3–8 | 0–5.21 | 26㎡ | 2 张 8 人实木长桌（倒角）+ 笔记本、2 块移动白板、1 台 55″ 移动投屏、每座插座 |
| 静音专注区 | 8–12 | 0–3.13 | 13㎡ | 10 软座 + 隔断屏风、2 个隔音电话亭、书架围合 |
| 展墙与主通道 | 0–3 | 4.17–8.33 | 12㎡ | **主入口在西墙**、8m 磁吸展墙（20 作品框 + 12 轨道射灯）、活动信息屏 |
| 后勤区 | 3–8 | 5.21–8.33 | 16㎡ | 储物架、洗涤槽、双门冷柜、员工位、卫生间门 |
| 讲座角（可变形） | 8–12 | 3.13–8.33 | 21㎡ | 40 把折叠椅、86″ 大屏、2 支无线麦、可移动隔断、小型音响 |

**房间外壳**：地板为单块 plane + `CanvasTexture`（1024² 程序化画 0.15m 胡桃木拼板，逐板色相抖动 ±6%）；保留**西墙**（含 1.1×2.2m 主入口门洞）与**北墙**（3 扇 2.4×1.6m 落地窗，窗台 0.9m）作为剖切立墙，东/南敞开便于观看；剖切断面加 `Edges` 深墨色描边 + 0.06m 踢脚线，让「切开」看起来是有意为之。天花为深胡桃面 + 9 盏琥珀圆顶吊灯（`#D98A3D` 灯罩 + 自发光灯面）。

**材质基调**：墙面 `#FAF3E7` 哑光；木质占比 ≥40% 由地板/天花/长桌/椅子承担；**墨绿只用于展墙毡面、静音区隔断与花盆**——保证奶油为主、胡桃为骨、墨绿为点的观感。绿植 ≥12 盆。

**家具生成**：全部程序化、低多边形、圆润厚重（动森感）。`kit/geometries.ts` 用 three 的 `RoundedBoxGeometry`（`three/examples/jsm/geometries/RoundedBoxGeometry.js`，比 drei `RoundedBox` 更适合做缓存复用）封装 `rounded(w,h,d,r)`，配合 `cyl()` 与 `BufferGeometryUtils.mergeGeometries` 合并零件；`kit/materials.ts` 按 `hex|rough|emissive` 记忆化 `MeshStandardMaterial`。禁止外部模型/HDR/网络字体。

**四时段（核心交互，驱动灯光 + 人群 + 数据）**

| 时段 | 光照 | 人群 | 讲座角布局 | 营收 |
|---|---|---|---|---|
| 08:30–10:30 安静期 | 晨光，仅半场灯（静音区 + 3 盏吊灯） | 3–5 人 | merged | 10% |
| 10:30–16:30 共创期 | 全亮日光 + 9 盏吊灯 | 长桌坐满约 16 人 | merged | 40% |
| 16:30–19:00 课程期 | 午后转暖橙，6 盏吊灯 | 讲座角满座 | lecture | 25% |
| 19:00–22:00 夜谈期 | 夜间：吊灯暖光为主，窗外校园楼亮灯 | 圆桌围坐 | circle | 25% |

灯光组具体取值（`LightRig`）：`ambientLight` 0.45/0.55/0.40/0.18（`#FFF3E0`）；`hemisphereLight` 天 `#FFF6E5` 地 `#6B4A32`，0.5/0.7/0.45/0.2；`directionalLight`（北窗日光）色 `#FFE9C7`/`#FFF8EC`/`#FFC08A`/关，强度 1.0/1.4/0.8/0，**唯一投影光源**（`shadow-mapSize 2048`，正交视锥覆盖 14×10）；吊灯 `pointLight` `#FFD9A0` 强度 6–9、`distance 5`、`decay 2`，按 3/9/6/9 盏开；夜景用窗外 14 栋校园楼的**自发光窗格**（`#FFC97A`）+ 一盏外部弱光冒充环境反射，避免真实反射探针。各屏幕（86″/55″/信息屏）用 `CanvasTexture` + 自发光面，随 mode 换内容。

**交互**：`ZonePicker` 在每区铺一块不可见拾取面，`onPointerOver/Out/Click` + drei `useCursor`；高亮 = 同尺寸半透明墨绿薄板（`emissive` + 呼吸透明度）+ `Edges`。`CameraRig` 用 `useFrame` 阻尼插值 OrbitControls 的 target 与相机位置（分区数据里带 `camOffset`），配「重置视角」按钮，不引入额外依赖。

**动画**：40 把椅子用 `<instancedMesh>`，三种布局的目标矩阵由 `data/layouts.ts` 纯函数产出；切换时逐实例 `easeInOutCubic` 插值 0.9s（按索引错峰 0.012s/把），隔断与大屏同步平移。人群按 mode 的占位清单淡入淡出（scale 0→1）。

**性能**：`dpr={[1,1.75]}`、PCFSoft 阴影且仅日光投影、几何与材质全局缓存、实例化只用在 40 椅 / 20 画框 / 14 楼 / 30 人 / 书籍这类重复件上（唯一家具保持独立 mesh，约 80 个）。

## UI 组成（全部用 animal-island-ui 真组件）

- 外壳：`<Cursor>` + `<Background type="dots-brown">`；章节间用 `<Divider type="wave-yellow"|"squiggle">`。
- 顶栏：`<Title variant="ribbon">` 站名 + `<Tag>` 标注「100㎡ · 单校区试点店」+ `<Button type="text">` 锚点导航。
- Hero 数字条：6 张 `<Card pattern color>`（100㎡ / 45–55 座·讲座 40 座 / 启动 38.5 万 / 月收入 7.2 万 / 盈亏平衡 日均 51 单·第 9 月 / 五条收入线），数字用 900 字重。
- 时段切换：`<Tabs items onChange>` 四档 + `<Tag>` 显示营收占比 + `<Progress variant="coffee-break">` 画占比条。
- 3D 舞台：圆角描边容器承载 `<SceneCanvas>`，角上叠 `<Button size="small">`（重置视角）与 `<Switch>`（显示人流 / 显示标签），底部 `<Tag variant="soft">` 分区图例。
- 分区详情：`<Card color pattern>` 面板（分区色 = 该区图例色，色名映射：吧台 `app-orange`／长桌 `app-teal`／静音 `app-blue`／讲座角 `warm-peach-pink`／展墙 `app-yellow`／后勤 `brown`），内含面积 `<Tag>`、主要活动、关键配置清单、「聚焦此分区」`<Button>`；窄屏退化为 `<Drawer>`。
- 六分区配置表：`<Table columns dataSource striped>`（分区/面积/主要活动/关键配置）。
- 五感氛围参数：`<Collapse>` 五个面板（视觉/听觉/嗅觉/触觉/可达性）。
- 一天四张脸：4 张 `<Card>`（时段 `<Tag>` + 营收 `<Progress>` + 「在 3D 中预览此时段」`<Button>`，点击即切换 3D 模式）。
- 可选：`<Button>`「看 2D 等距示意」→ 叠出 `public/reference/space.png`，与实时 3D 对照（该图正是同一空间的等距插画）。
- 页脚：`<Footer>` 放测算免责声明（非实际经营数据）+ 内容出处（企划书第三章）；右下 `<BackTop>`。

## 实施步骤

1. 建目录 + `package.json`（版本按上表精确锁定）、`tsconfig.json`、`vite.config.ts`、`index.html`；`npm install`；先跑通空白页 dev server。
2. 接入 animal-island-ui：`import 'animal-island-ui/style'`，用 Button/Card/Tabs/Table/Tag/Title/Divider/Progress/Background/Cursor 搭一个冒烟页，确认样式与字体加载正常（此步不过就别往下走）。
3. `styles/global.css`：材质色板变量 + 版式栅格 + 章节骨架。
4. `data/*.ts`：room / timeModes / layouts / content，全部逐字对齐 `03-space.html`（面积、座位、物件、时段、营收占比、五感标准）。
5. `kit/`（几何与材质缓存）+ `RoomShell`（地板/墙/窗/门/天花/吊灯）。
6. 六个分区的家具组件。
7. `ZonePicker`（拾取/高亮/标签）+ `CameraRig`（fly-to / 重置）。
8. `LightRig` 四时段灯光。
9. `fields/` 实例化（椅子/人群/画框/绿植/校园楼）+ 布局切换动画状态机。
10. `ui/` 各章节与 store 打通（Tab 切 mode、点分区出面板、时间线按钮回写 mode）。
11. 复制 `space.png` 到 `public/reference/`；写 README（启动方式、目录说明、数据出处）。

## 风险与回退

| 风险 | 回退 |
|---|---|
| react 浮动到 19.4 破坏 R3F peer | 四个 react 相关包写死 `19.3.0`，不带 `^` |
| vite 8（Rolldown 内核）与 animal-island-ui 的 CSS Modules 预哈希 shim 冲突 | 退回 vite 7 + @vitejs/plugin-react 5 |
| 字体体积约 3.4MB（Noto Sans SC 无 `unicode-range`） | 本地展示可接受；若要压体积，覆盖 `--animal-font-family` 去掉 Noto，回落到系统 CJK |
| 误改 ai-ui 内部类名（哈希类名不稳定，如 `.animal-card-app-teal-R5kFG`） | 只写自有容器样式 + 覆盖 `--animal-*` 变量，绝不命中其内部类 |
| drei `Environment` / `Text` 需要联网取资产 | 禁用两者；标签一律用 `<Html>`（真 DOM，走本地字体） |
| 40 椅 + 30 人 + 阴影导致掉帧 | 全部走实例化；仅日光投影；`dpr` 上限 1.5；必要时关掉电话亭等小件的阴影投射 |

### 与计划的偏差（如实记录）

| 计划 | 实际 | 原因 |
|---|---|---|
| `scene/` 按 `fields/` `furniture/` `kit/` 分目录 | 扁平为 `Zones/Furniture/HallZone/Occupants/ZoneLabels/Lighting/CameraRig/palette/instancing` | 六分区规模偏小，扁平少一层跳转；三个空目录已清理 |

### 遗留与建议

- **首屏体积**：字体 3.5MB 是大头（组件库自带 Noto Sans SC 三字重，无 `unicode-range` 分片）。若要对外发布，建议覆盖 `--animal-font-family` 回落系统 CJK，或对 woff2 做子集化。
